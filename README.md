# Mockup-StayMacth
StayMatch - ระบบหาบ้านและคัดกรองเจ้าของให้สุนัขจรจัด

StayMatch เป็นแพลตฟอร์มเว็บแอปพลิเคชันแบบ Single Page Application (SPA) ที่ออกแบบมาเพื่อช่วยเชื่อมโยงสุนัขจรจัดในศูนย์พักพิงให้ได้พบบ้านและเจ้าที่เหมาะสม ผ่านระบบคัดกรองอัจฉริยะ การปักหมุดที่พักอาศัยเพื่อประเมินสิ่งแวดล้อม และระบบจัดการหลังบ้านสำหรับเจ้าหน้าที่และผู้ดูแลระบบ

ฟีเจอร์หลักของระบบ
หน้าแรก (Landing Page):
แนะนำแพลตฟอร์มด้วยดีไซน์ Minimal/Editorial
แถบคำแรกเตอร์สุนัขด้วยอิโมจิสุดน่ารัก
ส่วนวิดีโอสาธิตการใช้งาน และคำถามที่พบบ่อย (FAQ Accordion)
หน้าผู้อุปการะ (Adopter Portal):
ค้นหาน้องหมาที่รอคอยบ้านด้วยระบบค้นหาเบื้องต้น
ฟอร์มสมัครรับเลี้ยงพร้อม ระบบจำลองการปักหมุดบ้าน (Map Pinning) เพื่อให้ศูนย์พักพิงใช้พิจารณาสภาพแวดล้อม
หน้าเจ้าหน้าที่ (Staff Dashboard):
จัดการข้อมูลสุนัข (เพิ่มข้อมูล, แก้ไขสถานะ)
ตรวจสอบคำขอรับเลี้ยง, นัดหมายสัมภาษณ์, สร้างสัญญา, อนุมัติ หรือปฏิเสธการรับเลี้ยง

แนวทางการออกแบบ (Design Language)
โทนสี: เน้นสีพาสเทลอ่อน (เหลือง #F2C62E / ชมพู #FAD3E6) บนพื้นหลังอุ่นๆ (#FAF9F4) และตัวหนังสือสีเข้ม (#20201D)
การใช้ภาพ: ใช้อิโมจิ (Emoji) แทนรูปภาพเพื่อความสะอาดตาและโหลดไว
ฟอนต์: ใช้ฟอนต์ภาษาไทย Sarabun จาก Google Fonts
เลย์เอาต์: เน้น Whitespace, เส้นขอบบางๆ (Hairline borders) และความโปร่งสบายตา

เทคโนโลยีที่ใช้
HTML5 / CSS3
Tailwind CSS (ผ่าน CDN)
JavaScript (Vanilla) สำหรับควบคุมการสลับ View, Tabs, Modals และระบบปักหมุดแผนที่

วิธีการใช้งานและการรันโปรเจกต์
เปิดไฟล์ผ่านเว็บเบราว์เซอร์ (Chrome, Firefox, Safari, Edge) ได้ทันที หรือใช้ Live Server ใน Visual Studio Code เพื่อความสะดวกในการพัฒนา
